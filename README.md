# app-starter

Template for every app: Codespaces dev container with Claude Code,
GitHub Actions tests, and Render deployment.

Read in this order: `run.py` -> `app/__init__.py` -> `app/routes.py` -> `tests/`.
Infrastructure: `.devcontainer/` (workbench), `.github/workflows/` (tests),
`render.yaml` (hosting), `CLAUDE.md` (rules for Claude Code).
